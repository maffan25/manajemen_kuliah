PANDUAN SAMASTA CORNER (v6)
===========================
FILE
- corner-icons.js  : pustaka ikon (megafon, perisai, dst) dan warna bola. Dimuat sebelum corner-home.js.
- corner-home.js   : kerucut berpegas halus (klik, seret, gulir) dan bola corner berikon.
- corner-app.js    : halaman corner, gerbang scan, Tentang Irjen (struktur interaktif), SOP dan Buku Panduan, pembukuan.
- corner.css       : seluruh gaya Corner.
- corner-data.js   : data (diedit lewat admin-corner.html). admin-corner.html : editor admin.
- ikon.css, ikon.js, rapot.js : dari kamu, ikut disertakan agar paket lengkap.

YANG BARU
1. Tab Penilaian di admin: ketik semua pertanyaan; jenis Bintang 1-5, Jawaban singkat, atau Paragraf; tiap pertanyaan Wajib/Opsional.
   Tiap event boleh punya pertanyaan dan kata penutup khusus.
2. Kata penutup dan sambutan bisa diedit. Tulis {nama} dan {event} untuk disisipkan otomatis.
3. Barcode dipindai -> halaman gerbang bertema (langkah: Data diri, Penilaian, Selesai) dengan konfeti.
4. Menu Irjen: Tentang Irjen (pengertian, tugas, struktur interaktif dari anggota.js), SOP dan Buku Panduan.
5. Menu baru di admin: "Profil lembaga" dan "SOP dan buku panduan" bisa dipakai corner lain juga.

PENTING: PERBARUI BACKEND
Tempel ulang apps-script-corner.gs.txt ke Apps Script, lalu Deployment BARU. Kolom K "Jawaban" ditambahkan; bila tab Absensi sudah ada,
isi judul "Jawaban" di K1. Tanpa ini, jawaban singkat tidak tersimpan.

Langkah sambungan Google Sheets, alur pemakaian, dan catatan lain sama seperti versi sebelumnya:
isi KODE_AKSES, jalankan setup, deploy Aplikasi web (Siapa saja), tempel URL /exec ke corner-config.js.
